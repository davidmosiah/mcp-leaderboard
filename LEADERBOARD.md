## Climb the board

Score your own server and see the itemized fixes:

```bash
npx -y mcp-scorecard <your-package-or-repo>
```

Then add the live badge to your README so agents (and humans) see your score:

```bash
npx -y mcp-scorecard <your-package> --badge
```

## Methodology

- Targets come from the official MCP registry (npm-installable servers only, latest active version).

- Each server is booted over stdio in its own child process with a hard timeout. This is a process boundary, not a security sandbox for untrusted packages. Servers that require auth before `listTools()` and don't honor the `MCP_PROBE` hook show as **unreachable** — not a low score, just not gradeable without credentials.

- Scoring is shape/metadata/discoverability only. A server can score 100 and still return wrong data. This grades agent-*readiness*, not correctness. See [mcp-scorecard checks](https://github.com/davidmosiah/mcp-scorecard#what-it-checks).
